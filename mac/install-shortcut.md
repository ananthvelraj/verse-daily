# Add Verse Daily to Mac Shortcuts

1. Open **Shortcuts** and create a new shortcut named **Verse Daily**.
2. Add the action **Run Shell Script**.
3. Paste: `python3 "/full/path/to/verse-daily/mac/word_of_the_day.py"`
4. Test it once. Then open **Shortcut Details** and choose **Add Keyboard Shortcut**, **Pin in Menu Bar**, or **Add to Dock**.
5. To see it every morning, open **Calendar**, create a repeating event, choose **Alert → Custom → Open file**, and select an exported app version of the shortcut. You can export the shortcut as an app from Shortcuts’ File menu.

The included script is already connected to this project’s GitHub repository.
